# Meletiq

**Thoughtful software. Useful by design.**

Meletiq is an independent software studio creating thoughtful, practical, and accessible software for everyday life.

## Our mission

Build useful digital tools that make everyday tasks simpler, with clarity, accessibility, and care at every step.

## Our vision

A world where well-designed software is within reach of more people, helping them spend less time on friction and more time on what matters.

## What we are exploring

- Browser extensions that make the web more useful.
- Mobile applications for everyday needs.
- Offline games for engaging moments of play.
- Productivity utilities and other practical digital tools.

These are areas of interest, not launched products. Product details will be shared as projects take shape.

## How we build

Our starting toolkit includes TypeScript, lightweight web tooling, Manifest V3, automated tests, and continuous integration. Technology choices will follow each product's needs.

We value thoughtful scope, approachable design, trustworthy behavior, accessible experiences, and purposeful innovation.
