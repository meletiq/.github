# Meletiq organization infrastructure

This repository hosts the public organization profile in `profile/README.md`, original lightweight branding in `assets/`, and shared contribution guidance.

**Thoughtful software. Useful by design.**

The organization is an independent software studio. No launched product, registered-company status, or team size is implied.

## Repository policy

Use `main` as the default branch. Keep unreleased commercial products private. Add access per repository only as needed. Never commit secrets. Agree on licensing before adding a license; these initial repositories have no license grant.

Public repositories may use Free-plan branch protections. Private repositories may have plan limitations; CI still runs. Do not enable paid security subscriptions or billable usage without owner approval.
